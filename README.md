# LinkedIn Jobs Dataset Analysis

This project analyzes a cleaned dataset of LinkedIn job postings, exploring trends in job titles and locations using Python.

---

## ✅ Features

- Loads and cleans LinkedIn jobs data
- Identifies the top job titles and job locations
- Exports cleaned data and visualizations
- Generates Excel summary and PNG bar charts

---

## 📦 Output

- `cleaned_jobs.xlsx` : cleaned dataset of job postings
- `top_job_titles.png` : bar chart of most frequent job titles
- `top_job_locations.png` : bar chart of most frequent job locations

---

## 🛠️ Tools Used

- Python
- pandas
- seaborn / matplotlib
- openpyxl

---

## ▶️ To Run

```bash
python linkedin_analysis.py
